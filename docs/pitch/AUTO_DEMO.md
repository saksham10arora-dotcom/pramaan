# Auto-demo: 63 second voice-over video

Page khud chalta hai, captions ke saath, jaise FORGE demo me tha. Tumhe sirf bolna hai.

## Record karne ke steps

1. Chrome me kholo: https://pramaan-teal.vercel.app/?tour=1
2. Chrome full screen karo (Ctrl + Cmd + F).
3. **Cmd + Shift + 5** dabao, **Record Entire Screen** chuno, Options me mic select karo, Record dabao.
4. Page pe **Start demo** dabao aur neeche ki script bolo.
5. Aakhri card pe ruk ke menu bar me Stop dabao.

Captions ke upar patli line bhar rahi hoti hai: wo bhar jaaye toh agli line.

## Bolne ki script

| Screen | Bolo |
|---|---|
| Title card (7 sec) | Ye hai Pramaan. AICTE approval ke har application ka verdict, proof ke saath. |
| Clean (6 sec) | Ye ek sahi application hai. Pramaan ne har document padha aur handbook se check kiya. |
| Evidence (7 sec) | Har result apna source dikhata hai. Faculty ratio aur building area, room by room. |
| Forged (5 sec) | Ye forged fire certificate hai. Expired date ke upar nayi date type ki gayi. |
| White box (8 sec) | Aankh se theek lagta hai, par Pramaan neeche ki asli date padh leta hai aur dikhata hai kahan chhedchhad hui. |
| Scanned (9 sec) | Print aur scan karne se edit ke nishaan mit gaye. Par QR code me abhi bhi asli date hai, toh ye bhi reject. |
| Ghost (10 sec) | Ye doosra college hai. Har file theek lagti hai, par iski 25 faculty pehle se doosre institution ki list me hain. Ek file dekh ke ye kabhi nahi pakda ja sakta. |
| Queue (6 sec) | Officer ko ek queue milti hai, sabse risky pehle, har application ki report ke saath. |
| End card | AI proposes, code verifies. Jahan shak hai, wahan faisla insaan ka. |
